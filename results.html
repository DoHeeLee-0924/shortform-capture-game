실험 데이터 초기화

로컬 데이터 초기화는 현재 브라우저에 저장된 임시 결과만 삭제합니다.
온라인 데이터 전체 삭제는 Google Sheet의 responses 시트에서 참가자 행을 삭제하는 기능입니다.

온라인 삭제 버튼이 invalid action으로 실패하면, 현재 Apps Script가 삭제 기능을 아직 지원하지 않는 상태입니다. 이 경우 google_apps_script.gs에 action=clear 기능도 추가해야 실제 Google Sheet 데이터 삭제가 됩니다.

온라인 실험 데이터를 삭제할까요?

Google Sheet의 누적 실험 데이터가 삭제됩니다. 보통 1행 컬럼명은 유지하고, 2행 이후 참가자 응답만 삭제합니다.

계속하려면 아래 입력창에 DELETE를 입력하세요.
